FastAPI Service Design and Observability

Exposing the RAG pipeline over HTTP with FastAPI provides automatic OpenAPI schema validation via Pydantic models and low-overhead JSON serialization.

Configuration Hygiene

All runtime parameters—including database paths, chunk sizes, similarity thresholds, and API keys—must be injected through environment variables. Hardcoding secrets in source files risks credential leaks in version control.

Per-Query Telemetry

Every query response and JSONL log entry records retrieval latency in milliseconds, end-to-end latency, number of retrieved chunks, and prompt plus completion token counts for cost tracking.
